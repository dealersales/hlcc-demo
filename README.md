# Holton Le Clay Cars — demo preview

Static export of the DSC dealer demo for Holton Le Clay Cars, published at https://dealersales.github.io/hlcc-demo/. Generated by `../export_static.py` from the PHP build; do not edit these files by hand — edit the build and re-export.

Prices, stock, address and contact details are Woody's own. Monthly payments and any representative APR are deliberately absent until the client's FCA position is confirmed.
