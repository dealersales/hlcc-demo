# hlcc-demo

Static preview build of the **Holton Le Clay Cars** dealership site, published for client review only.

- **Live preview:** https://dealersales.github.io/hlcc-demo/
- **Status:** preview — not the production site. Every page carries `<meta name="robots" content="noindex, nofollow">` and a canonical pointing at the Pages host, so nothing here is indexed or competes with the live dealership domain.
- **Stock:** real vehicles and prices as supplied by the dealership.

Built and maintained by Digital Sales Consultants Ltd. Do not point a client domain at this repo — production builds are deployed separately.
